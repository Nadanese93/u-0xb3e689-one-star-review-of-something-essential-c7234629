A make.fun bounty entry ($5 prize, top 5 × $1) for "One-Star Review of Something Essential": a one-star review, 1–160 characters, of something essential — here, socks and the dryer that keeps losing them.

Run `python3 main.py` and it writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
